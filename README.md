## Reproducibility

Install Python dependencies and run:

```bash
make verify
make exposition
make paper
```

Or run the complete local-equivalent gate:

```bash
make all
```

- `make verify` runs symbolic identities, numerical checks, and pytest regression tests.
- `make exposition` regenerates and validates the Stage-10 approved policy-regime figure from the frozen threshold equation.
- `make paper` depends on `make exposition` and then builds `paper/main.pdf` from the modular LaTeX source and bibliography.
